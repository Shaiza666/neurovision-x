# Splits

JSON files listing patient ids for train, validation, and test. Generated by `scripts/prepare_splits.py` or `scripts/download_msd_task01.py`. Patients never appear in more than one split.

`msd_task01_patients.json` is the seed-2026 70/10/20 split of all labeled MSD Task01 cases (ids only, no voxels). `msd_task01_cpu_patients.json` is the reduced prefix used for the CPU experiment, with the `training/` / `validation/` / `test/` prefixes the loader records.
